03 / Mandala interactiva

Sobre el proyecto

Este proyecto es un mandala interactiva animada, donde se pueden observar patrones geométricos que se mueven y cambian en tiempo real, al presionar el mouse se puede ver como la mandala cambia a sus colores opuestos.

Referente visual

Mandala basica

Esta imagen representa una mandala básica, un diseño simétrico que se utiliza a menudo en artes decorativas y terapéuticas, pero en este caso al sketch se le incluyen efectos de animados.
